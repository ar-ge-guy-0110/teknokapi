# Tekno Kapı

TeknoKapı Web Application is a full-fledged e-commerce web application. TeknoKapı Web Application is a fully dynamic,
administrator panel and modules where every setting of the application is managed and can manage and change all
from product management to user management, and customer user panel modules, products
modules, cart module; order, comment, rating, favorite, past orders, password reset, registration
modules, payment modules and secure payment modules ready to connect to bank APIs for payment
process, payment type selection, address addition and address selection, cancellation/return/change page, money transfer module, about us page, our bank accounts
page, support page, privacy agreement page, contact page, where is my cargo page,
terms of use page, distance sales page, delivery page, membership agreement page,
it is a robust e-commerce web application equipped with security algorithms and security
functions.
